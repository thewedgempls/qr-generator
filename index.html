QR Code Generator

For LHENA Volunteer Network. Runs entirely in your browser. Nothing you type is sent anywhere, and the code points straight to your link, with no redirect or scan tracking.

Before you print

  • Scan the code with a phone before printing. Check that it opens the right page.
  • Keep dark code on a light background. Low contrast or inverted colors fail on some scanners.
  • Keep at least 2 cm (about 3/4 in) printed size and leave the white border intact.
  • The code is only as private as the page it links to. If the destination site uses analytics, visitors are tracked there.
  • Avoid link shorteners (bit.ly and similar). They log every click. Link directly to the final page.
